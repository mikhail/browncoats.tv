# browncoats.tv

A lightweight static website for browncoats.tv.

## Local preview

From this directory:

```powershell
python -m http.server 4173
```

Then open <http://localhost:4173>.

## Deployment

This repo is plain static HTML, CSS, and JavaScript. It can be deployed to GitHub Pages, Netlify, Cloudflare Pages, Firebase Hosting, or any static host.

When the host is ready, point the Namecheap DNS records for `browncoats.tv` at the hosting provider.
